# v0.5.0 · 快速 TODO 与时间信息

## 更新与使用

本机 desktop profile 已通过 link 指向本项目的前后端插件。完全退出 DSH，再重新打开，在“任务日志”验收。无需重复安装；重启时自动为原数据库补充截止日期字段和 TODO 表。原任务、时间、附件和历史保留。

1. 点击左侧“快速 TODO”打开侧面板。入口高亮表示已选中；再次点击或使用关闭按钮退出，入口恢复中性状态，不显示展开/收起文字及箭头。Escape 也可关闭，焦点返回入口。
2. 输入随手事项，Enter 或“记录 TODO”保存。成功后清空输入并保持焦点，可继续输入；失败保留内容，支持重试。未提交草稿在关闭面板、切换 quest 时保留，离开页面或重启不保留未提交草稿。
3. 选择 quest 后可指定“作为新目标”或“作为进展 · 某个目标”，点击“保存并转入”，无需再整理第二份副本。默认不关联 quest。
4. 已有 TODO 点击“转入 quest”，检查完整路径后确认。转入保留建立时间、完成时间、完成状态和 DDL；未完成 TODO 仍未完成。已完成 TODO 在折叠列表内也可以转入。
5. 转入后待整理数量减少，当前 quest 大纲刷新、高亮新项约 6 秒；提示提供“查看”“撤销”。转入其他 quest 时保持当前页面，可主动查看。
6. TODO 的“…”提供标题编辑、时间和删除。删除可从提示撤销。“已完成”“已转入”默认折叠。已转入是来源记录，后续在 quest 内维护实际事项。
7. quest、目标、进展和 TODO 都可以通过“…”菜单（支持右键）打开“时间与截止日期”。已有 DDL 时直接点日期标签。时间卡展示含年份、星期的建立、更新、完成时间，未完成显示“尚未完成”，缺失历史显示“未记录”。
8. DDL 可选按日或具体时间，保存或清除。按日包含当地当天，具体时间使用本地时区选择、按绝对时间保存。今天截止用金色、逾期用红色文字和时钟符号；已完成不继续报逾期。日期提示每分钟更新。

## 规则

- 原子转入：新建节点与 TODO 转入标记同时保存；失败均不生效。记录和转入均支持重试，不重复创建。
- 撤销仅删除本次生成且未发生后续修改的节点。节点已编辑、完成、添加子项/附件、移动或所属 quest 已归档时，拒绝撤销并说明原因，保留当前内容。提示携带目标 ID，防止旧撤销操作影响后来再次转入的内容。
- 已完成 quest 允许转入，但明确提示且不自动重开父项；归档 quest 不可选、不可写。删除的原节点不会重新变成可编辑 TODO；已转入记录保留，查看时提示原节点不存在。
- 父子 DDL 独立；晚于上级时给出提示，允许明确保存，不改动上级或完成状态。创建/完成时间只读，取消完成清空当前完成时间，历史仍保留。
- DSH 正在预览的当前 quest 需先确认或取消，才能在此界面把 TODO 转进去。普通记录与其他 quest 不受影响；服务端预览版本校验仍可检测外部并发修改。
- 本轮不添加通知、日历同步或指令框中的自然语言日期识别。Agent 通用工具支持显式截止字段与 TODO 操作，复用后端校验。
- `preview/index.html` 是旧版独立演示；`docs/prototypes/todo-and-dates.html` 是独立设计原型。实际功能在 DSH 内使用。

## 数据与接口

- 各级事项新增 `due_date: YYYY-MM-DD | null`、`due_at: epoch ms | null`，互斥；均空表示无 DDL。旧数据自动补空，不补造截止日期。
- `todos` 保存独立事项、完成与截止时间、删除标记、请求幂等键、转入引用和撤销校验快照；`todo_events` 保存变更历史。`events` 同时记录 quest 内的转入与撤销。
- `GET /quest-journal/todos` 需要现有鉴权。写操作走同源受保护的 `/ops`，支持 `create_todo`、`update_todo`、`convert_todo`、`undo_todo_conversion`、`delete_todo`、`restore_todo`。`update_node` 支持截止字段。
- `quest_list_todos` 读取 TODO；`quest_apply_changes` 可调用相同 TODO 操作，记录来源 agent。日期编辑同样支持 `quest_update_node`。
- 导出脚本为新库附带 TODO 与 TODO 历史，仍可读取没有新表的旧库。旧 preview 只显示原任务结构，不展示 TODO。

- `bash scripts/run-tests.sh`：旧功能、旧库迁移、截止校验、持久化、原子回滚、状态和时间保留、重复请求、撤销冲突、HTTP 鉴权及 Agent 接线。

- `QJ_BROWSER_TEST=test/browser-todos.test.mjs QJ_BROWSER_HARNESS=test/browser-todos-harness.mjs python3 scripts/test-browser-drag.py`：实际 React 界面 + HTTP + 隔离 SQLite，验证失败重试、连续记录焦点、编辑与删除撤销、指定目标转入、转入撤销、日期与具体时间、小屏确认按钮、一步记录转入及完成计数。

浏览器验证使用独立测试数据和本机已安装 DSH 的 React 资源，不接触真实任务，不调用模型。未自动重启用户的 DSH；真实桌面验收需按上述步骤完成。
