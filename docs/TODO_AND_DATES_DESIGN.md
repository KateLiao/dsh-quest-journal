# 快速 TODO 与事项时间 · 交互设计提案

状态：方案已确认，已实现于 v0.5.0。交互原型使用独立演示数据，实际使用与验收见 `TODO_AND_DATES.md`。

## 1. 设计目标

随手记录时无需先决定层级；整理时明确放入哪个 quest、哪个目标；查看时让事项标题占据主要空间。复用现有暖黑色、金色选中态和三层大纲，不增加每行常驻操作按钮。

## 2. 快速 TODO

- 左侧任务列表上方常驻“快速 TODO”入口，数字仅统计未完成且尚未转入的 TODO。入口与当前 quest 无关，切换任务不会丢失草稿。
- 快速 TODO 入口仅用选中/未选中样式表示面板状态：选中时使用金色边框、底色和左侧指示条，未选中时恢复中性样式；不显示展开/收起文字或方向箭头。入口名称和计数保持不变；关闭按钮及 Escape 同步选中状态，关闭后焦点回到入口。使用 aria-pressed / aria-controls 表达按钮状态及关联面板。
- 点击打开右侧抽屉，保留当前任务上下文。单行输入，Enter 保存，输入法组词回车不提交；成功后清空并保持焦点。空白不保存，保存失败保留内容并允许重试。
- 记录时 quest 可选，默认“不关联”。选择关联项时显示“保存并转入”，提交后立即转入选中位置，不留下第二份独立待办。单纯记录用“记录 TODO”。
- 已记录的 TODO 可勾选完成、编辑标题、设置 DDL，或“转入 quest”。更多菜单收纳删除；删除支持撤销。已完成默认折叠，可重新打开。
- 抽屉关闭保留未提交文字；本地原型仅模拟行为，正式版 TODO 与转换记录持久化到现有数据库。

## 3. 转入 quest 的确定性规则

- 打开转入面板：先选择未归档 quest，可搜索；默认当前打开的 quest，但明确展示名称，用户可更换。
- 放置位置默认“作为新目标”；也可选择一个已有目标，作为它的进展。新目标允许日后继续加进展，不额外制造“待整理”层。
- 提交前展示路径，例如“配合跟进 示例项目 A → 完成 PRD → 与协作者同步思路”。按钮文案“确认转入”。
- 转入保留标题、建立时间、DDL、完成状态和完成时间；新增转换时间及来源引用。未完成项保持未完成。已完成项也可从已完成列表转入，转入前明确提示将保留完成状态。
- 转换必须原子完成：创建节点和标记 TODO 已转入一并提交。重复点击/网络重试不产生重复节点。失败时原 TODO 留在列表，错误就地显示，目标失效时要求重新选择。
- 转入成功从 TODO 待办区移除，更新计数；若目标就是当前 quest，大纲立即出现并短暂高亮；提供“查看”和“撤销”。转到其他 quest 不强制跳走。
- 转入记录可在“已转入”中回查并跳转；不是两个可独立编辑的副本。撤销恢复原 TODO，仅当对应节点及其子项未被后续修改时执行；已有后续编辑则说明原因并保留现状。
- 归档 quest 不可选；完成的 quest 可选，但给出提示且不自动重开父项。目标不明确时不凭标题猜测位置。

## 4. 事项时间与 DDL

适用 TODO、quest、目标、进展。默认每行只展示标题、完成状态及已设置的 DDL；建立/完成/更新时间不常驻铺开。

- 每行现有“…”菜单增加“时间与截止日期”；右键打开同一菜单。触屏与键盘始终可通过“…”访问，右键不是唯一入口。
- 点击 DDL 日期标签，或选择上述菜单，在当前条目下方展开一张紧凑时间卡，不遮挡相邻标题。卡内显示“建立”“最近更新”“完成”“截止日期”，含年份、日期、星期；系统时间展示本地时区。
- 卡片可收起，不触发完成或标题编辑，不与拖动混淆；支持 Escape 关闭。一次只展开一项。点击空白不丢失正在编辑的截止日期。
- 建立、更新和完成时间只读。未完成显示“尚未完成”；历史数据缺失显示“未记录”，不补造历史时间。取消完成清空当前完成时间，历次完成行为仍保留历史。
- DDL 默认按日，支持可选具体时间；选择后点“保存”，支持清除。仅日期在当地当天结束后算逾期；具体时间按当地所选时间转换为统一时间戳存储，跨电脑依日期/绝对时间语义分别展示。
- 行内标签：未来用中性色，今天用金色，“逾期 N 天”用红色文字和图标；已完成用淡色显示“已完成”，不继续报逾期。颜色之外始终保留文字。
- 父子 DDL 独立，不自动覆盖。子项晚于父项时在编辑卡内提示，仍可明确保存。阻塞不改变 DDL，不自动完成/重开父子节点。
- 本轮不附带系统通知、日历同步或自然语言自动识别日期；后续 DSH 写 DDL 时复用相同字段与预览确认流程。

## 5. 实施与验收范围

新增 TODO 实体（稳定 ID、标题、状态、建立/更新/完成时间、截止日期、转入引用），各级节点补充可空截止字段；日期型与时间型明确区分。迁移旧库时截止日期为空，不清空原数据。转换、撤销、日期编辑写入历史；归档仍只读。Agent/HTTP 与手动编辑共享校验。

验收：不选 quest 可连续记录；选 quest 可一步保存并转入；已有 TODO 可转成目标或进展；转换后无重复、时间保留、失败可重试；小屏确认区始终可见；同一操作重复确认不重复创建；完成后计数正确；跨重启保留；所有层级可展开时间和清除 DDL；无日期、逾期、已完成及历史缺失均有清楚状态；键盘、触屏均有可用入口。

## 6. 原型边界

`prototypes/todo-and-dates.html` 是可独立打开的高保真 HTML，包含抽屉、输入、选择位置、转入高亮、撤销、勾选完成、时间展开和日期保存演示。数据仅在本页内存中，刷新恢复，不连接真实 quest，不代表已开发完成。正式功能已在插件中实现；原型独立保留用于设计参考。
