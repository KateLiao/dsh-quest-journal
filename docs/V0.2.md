# v0.2 实施与验证

依据用户在聊天中提供的 v0.2 正文及 README / DATA_MODEL / ACCEPTANCE 中的初版约定实现。磁盘上的 `v0.2 需求.md` 带 TSD 二进制标头，未覆盖该文件。

## 已实现

- 进行中列表：搜索、完成/阻塞/优先级筛选；手动、优先级、最近更新、添加日期排序；手动模式使用拖拽柄调整顺序并保存；明确高亮选中任务。
- 各级任务：默认 P1，可选择 P0/P1/P2；显示添加时间、最近更新时间及星期；子节点和备注变化更新上级时间。
- 双击标题编辑，失焦保存；Enter 保存并打开同级新条目的输入框；Tab 将目标降为前一个目标的 Step；标题开头 Backspace 或 Shift+Tab 将 Step 升为 Objective。中文输入法组词期间不触发快捷操作。
- 维持原始 Quest → Objective → Step 三层约束：Quest 不能再升级、Step 不能再降级；带子 Step 的目标需先移走子条目再降级，避免丢失结构。目标升为独立 Quest 未实现。
- 删除按钮要求输入“删除”，级联清理子节点与附件，保留变更事件。归档任务禁止编辑。
- 新增、阻塞、备注、链接等改用面板内表单，移除对原生 prompt 的依赖。原问题疑似与嵌入式环境不支持原生弹窗有关，尚未在真实 DSH 中复现根因。
- 修复 Step 附件读取缺失、已有链接编辑绕过校验、已阻塞节点无法更新原因，以及无效 changes 请求静默成功。
- Agent update_node 支持 priority，apply_changes 支持 move_node / delete_node。
- 旧数据库打开时自动补充 priority、updated_at，不清空原有任务。

## 验证

`bash scripts/run-tests.sh`：核心 20 项、预览导入 25 项、路由 19 项全部通过；新增客户端冒烟验证加载、选中、新增表单及阻塞表单到请求的完整链路。

客户端测试使用 React hooks 和请求替身，未替代真实浏览器及 DSH 运行时验收。尚需在 DSH 中验证键盘焦点、拖拽和布局；未修改已安装 profile 或重启 DSH。`preview/index.html` 保留初版演示，不作为 v0.2 功能入口。
