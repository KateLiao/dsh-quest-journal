# v0.3 使用与验收

## 使用

当前 desktop profile 已链接本项目的两个插件包。完全退出 DSH 后重新打开，在侧栏进入“任务日志”；无需重新安装，也不需要额外 API Key。

1. 选中需要更新的任务，确认标题。
2. 在“用 DSH 整理任务”中输入进展或下一步，点“生成变更”（或 Ctrl/⌘+Enter；普通 Enter 换行）。
3. 直接在下方“目标与进展”查看模拟结果：新增/修改/移动边框高亮，删除项保留并标为将删除，尚未写库。如果 DSH 提问，直接在输入框补充回答。
4. 点击“应用 N 项变更”。面板与 Trace 刷新，来源为 agent。
5. 预览不对时补充要求再次生成，或取消预览。生成失败保留文字；生成中可取消。若应用返回网络错误，重新点应用，服务端避免重复创建。

指令服务复用 DSH **默认模型**（agentDefaultModel.currentSelection），不继承某个聊天的临时模型选择。请确保默认模型可正常调用。如果显示服务未就绪，先确认 DSH 模型配置。新指令框没有开放聊天、外部发信或调研工具，仅做当前任务的编排和状态更新。

## 首次验收示例

建议在测试 Quest 中输入：

> 现在我在优化PRD，下一步计划和 协作者 同步思路、找研发算法确认指标、调研了解仿真平台。

预期：预览“完成 PRD”目标，描述为正在优化 PRD，下面三个未完成子项：和 协作者 同步思路、找研发算法确认指标、调研了解仿真平台。确认后才真实创建。若已有明确对应的 PRD 目标，模型应复用它；有多个同名目标则澄清。

继续输入：

> 和 协作者 同步思路已完成；找研发算法确认指标因等待数据而阻塞；完成 PRD 的优先级设为 P0。

预期：预览三个修改，不自动完成 PRD，不把阻塞等同于完成，不发送消息给 协作者。

在预览生成后手动修改一条任务，再点应用，预期提示任务已更新，要求重新生成。应用成功后重复确认及重启后读取，不应重复创建。

## UI 验收

- 列表搜索和筛选/排序占用紧凑空间；当前任务高亮；手动排序支持柄拖动。
- 各行标题优先展示，只保留完成、折叠、按需新增和更多按钮；更多菜单提供优先级、阻塞、标题、备注、链接、层级、删除与 Quest 归档。
- 阻塞原因独立展示；日期在详情中查看；附件以最新一条摘要入口展示；历史默认折叠。
- 双击编辑、失焦保存；Enter 进入同级新条目行内输入；Tab/Shift+Tab/行首 Backspace 沿用 Objective↔Step 的层级限制。
- 归档只读；隐藏已完成与折叠目标可用；小屏重排，触屏仍保留操作入口。
- 旧版本正文中独立手写的“优先级：P0”等元数据行不再展示，数据库原文不改写；正常描述保持原样。实际优先级以结构化 badge 为准，可在更多菜单中核对修改。
